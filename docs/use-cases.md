# Use Cases

## UC1 — Identify benefits in historical contracts

**Actor:** Project / portfolio analyst  
**Input:** One or more project contracts in PDF.  
**Process:** Extract deliverables, compare them with a benefits catalog, and generate a structured mapping.  
**Output:** Benefit associations, categories, contribution scores, and rationales.  
**Decision value:** Converts contract-centric information into a value-oriented view of the project.

## UC2 — Improve a new project proposal

**Actor:** Researcher or project leader  
**Input:** Project objective and proposed deliverables.  
**Process:** Analyze the proposal against the benefits catalog.  
**Output:** Recommendations to clarify objectives, strengthen benefit coverage, and make deliverables more measurable.  
**Decision value:** Brings benefit thinking into project formulation rather than waiting until project closure.

## UC3 — Review from a portfolio / PMO perspective

**Actor:** Portfolio manager / PMO  
**Input:** Proposed objective and deliverables.  
**Process:** Analyze not only direct project benefits but also portfolio-level implications.  
**Output:** Recommendations focused on broader value, alignment, and portfolio contribution.  
**Decision value:** Connects individual initiatives to portfolio-level value management.

## UC4 — Future benefit realization monitoring

**Actor:** Portfolio manager  
**Input:** Benefit baselines, targets, evidence, and execution data.  
**Process:** Compare expected vs. realized benefits and detect emerging deviations.  
**Output:** Alerts, explanations, and recommended corrective actions.  
**Status:** Roadmap, not yet implemented in the current PoC.
