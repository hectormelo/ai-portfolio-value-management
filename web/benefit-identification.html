Identificación de Beneficios desde Contratos

Selecciona uno o varios contratos en PDF. Cada uno se sube al agente, se procesa y se muestra el JSON de beneficios identificados.

Configuración de conexión
Sin la ruta /api. Ej: http://localhost:7860
Si falla, prueba con "file_path" o "files".
La configuración se guarda solo en este navegador (localStorage). La API Key nunca se envía a otro sitio.
