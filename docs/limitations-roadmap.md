# Limitations and Roadmap

## Current limitations

- The proof of concept has been validated on a small number of contracts.
- A suggested benefit may not materialize in practice.
- Relationships between deliverables and benefits can be indirect.
- LLM outputs can be incomplete or inaccurate.
- Outputs require validation by people who understand the project context.
- Real execution/impact evidence is not yet incorporated into the recommendation loop.
- Recommendation quality has not yet been formally evaluated at scale.
- The current PoC is not integrated with institutional portfolio systems.
- Cross-project information for detecting synergies and overlaps is still limited.

## Roadmap

### 1. Functional validation

Evaluate usefulness with project leaders and portfolio managers, comparing AI recommendations with final human decisions.

### 2. Larger evaluation set

Expand the number and diversity of projects and contracts used for testing.

### 3. Historical benefit knowledge base

Persist project-benefit relationships in a vector / semantic knowledge base to retrieve comparable historical cases and improve recommendations.

### 4. Benefit realization monitoring agent

Add an agent that tracks baselines, targets, indicators, and execution evidence; compares expected vs. realized benefits; and generates alerts.

### 5. Predictive analytics

Estimate the likelihood and timing of benefit realization based on historical project patterns and current evidence.

### 6. Prescriptive portfolio support

Use multicriteria and optimization techniques to prioritize benefits, actions, and resource allocation under portfolio constraints.

### 7. Stronger governance

Add evaluation criteria, audit trails, security controls, permissions, and explainability requirements before institutional adoption.
