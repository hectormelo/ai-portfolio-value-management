# Benefit Identification — User Guide

1. Start Ollama and verify Qwen2.5 is available.
2. Start Langflow and import `flows/benefit-identification-flow.json`.
3. Load `data/sample-benefits-catalog.json` in the relevant file node.
4. Serve the `web/` directory with `python -m http.server 8000`.
5. Open `http://localhost:8000/benefit-identification.html`.
6. Enter the Flow ID and local connection parameters generated by your Langflow instance.
7. Select one or more PDF project documents and process them.
8. Review the structured benefit mapping and validate it with a project/portfolio expert.

> Do not upload confidential documents to a public deployment. The original PoC was designed for local processing.
