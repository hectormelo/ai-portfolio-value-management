# Pre-Publication Checklist

- [ ] Revoke/rotate any API key that was previously embedded in local HTML or Langflow exports.
- [ ] Confirm no real project contracts are included.
- [ ] Confirm no personal/local filesystem paths remain.
- [ ] Decide whether the institution-specific benefits catalog can legally be published; otherwise keep the synthetic sample.
- [ ] Confirm screenshots do not expose project names, financial values, emails, IDs, or internal URLs.
- [ ] Confirm you have permission to use institutional names/logos if you plan to mention them.
- [ ] Add a license only after confirming ownership/publication rights.
- [ ] Create a short demo GIF/video or screenshots using synthetic data.
- [ ] Pin this repository on your GitHub profile.
