# Benefit Recommendation — User Guide

1. Start Ollama and verify Qwen2.5 is available.
2. Start Langflow and import `flows/benefit-recommendation-flow.json`.
3. Load `data/sample-benefits-catalog.json` in the relevant file node.
4. Serve the `web/` directory with `python -m http.server 8000`.
5. Open `http://localhost:8000/benefit-recommendation.html`.
6. Enter the Flow ID and local connection parameters generated by your Langflow instance.
7. Select the intended perspective (project/researcher or portfolio/PMO).
8. Enter the project objective and proposed deliverables.
9. Review the recommendations and validate them before changing the project proposal.
